# GitTUI

A terminal-based user interface for Git, built with .NET 8 and Terminal.Gui.

## Description

GitTUI provides a simple, keyboard-driven interface for common Git operations. It allows you to view your repository status, stage/unstage files, and commit changes without leaving your terminal.

## Installation

You can install GitTUI globally via NPM:

```bash
npm install -g @ferquo/gittui
```

## Usage

Once installed, simply run:

```bash
gittui
```

Navigate the interface using your keyboard.

## Features

- View repository status
- Stage and unstage files
- Commit changes
- Cross-platform support (Windows, Linux, macOS)
